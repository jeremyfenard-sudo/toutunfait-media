# Médias de Tout un fait

Les images des carrousels publiés par [@tout.un.fait](https://www.instagram.com/tout.un.fait/), un média de
culture générale qui publie des faits vrais mais surprenants, chacun vérifié avec deux sources minimum.

Ce dépôt n'est qu'un hébergement : l'API Instagram va chercher les images sur une URL publique.
Un dossier par fait (`F0026/`), avec les slides en JPEG et la légende du post (`F0026.legende.txt`)
qui porte les sources et les crédits complets de chaque image.

## Crédits et licences

Chaque image reprise porte sa provenance sur la slide et dans la légende : auteur, licence, source.
Les images viennent d'archives et de fonds libres (Wikimedia Commons, musées, NASA) sous domaine public,
CC0, CC BY ou CC BY-SA ; les cartes sont tracées depuis les données OpenStreetMap (© contributeurs
OpenStreetMap, ODbL). Les slides elles-mêmes sont © Tout un fait.
